# 科技型小微企业风险定价模型

## 论文背景

本仓库是硕士论文《对低息差背景下银行差异化经营路径的研究——科技型小微企业综合经营"看不清、定不准、绑不牢"的破解之道》的实证建模部分。

## 模型概述

### 核心问题

科技型小微企业信贷面临**"三难"困境**：

| 难题 | 含义 | 模型应对 |
|------|------|----------|
| **看不清** | 信息不对称，财务数据缺失 | 信息不确定性溢价 Π^UNC |
| **定不准** | 传统定价模型过于理想化 | Logistic PD + 交互项 + 非预期损失 |
| **绑不牢** | 优质客户易流失 | 综合贡献折扣 Π^STR + 区域竞争折扣 Π^REG |

### 去理想化定价公式

```
R_i = max{ R_floor ,  R_floor + Π_i }

Π_i = PD_i·LGD_i          （预期损失溢价 Π^EL）
    + κ·√[PD_i(1-PD_i)]   （非预期损失溢价 Π^UL）
    + λ(1-q_i)(EL+UL)     （信息不透明度溢价 Π^UNC）
    − δ·S_i               （综合贡献折扣 Π^STR）
    − γ·C_i               （区域竞争折扣 Π^REG）

R_floor = FTP + c_op + ρ_0 = 4.5%
```

### 八大因子体系

| 维度 | 指标 |
|------|------|
| 行业属性 | 行业赛道（硬科技/软科技/传统转型）、研发投入强度 |
| 显性财务 | 营收增长率、杠杆率、流动比率、净资产规模 |
| 隐性偿债能力 | 经营现金流覆盖倍数、创始人经验、逾期次数、股权稳定性 |
| 经营周期 | 企业生命周期阶段 |
| 客户综合贡献 | 存款沉淀率、交叉销售数、合作年限、供应链深度 |
| 区域环境 | 区域竞争程度 |
| 担保方式 | 抵质押覆盖率、专利数量/质量/质押、政府增信 |
| 结算流水 | 结算归一化指标 |

## 对比模型说明

本模型与三种常见定价方式进行了对比：

1. **LPR 固定利率模型**：一刀切定价，无法区分风险
2. **仅 EL 覆盖模型**：仅覆盖预期损失，忽略非预期损失和信息不对称
3. **朴素线性加和模型**：`R = R₀ + ΣαᵢFᵢ + ε`，忽略因子非线性、交互效应、信息不确定性
4. **去理想化模型（本文）**：PD 概率模型 + 交互项 + UL 凸性 + 信息溢价 + 战略折扣
